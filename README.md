# Escout

Escout is a private, personal-use research tool. It runs in its owner's own web browser and is not distributed, sold or offered to the public.

## What it does

- While the owner browses Etsy search results, it helps them review competing listings. It reads publicly visible listing information (titles, descriptions, tags), aggregate public shop statistics (total sales, number of active listings, shop age) and public per-listing statistics (favorites, views).
- Tags and shop statistics are read through Etsy's Open API v3, using the owner's own Etsy developer account.

## What it does not do

- It does not upload, edit or modify any listings or shops.
- It does not access private order, customer or transaction details.
- It does not send emails or messages.
- It does not ask anyone else to create, request or share Etsy API credentials, and no credentials are published anywhere.
